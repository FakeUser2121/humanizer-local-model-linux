First run

This app does not download or run a model. It sends your text to a llama.cpp server that you run yourself.

  • llama.cppllama-server, any machine
  • /completionexact training prompt
  • Privateyour text only goes to your server

Start your server first, for example:

llama-server -m humanizer-12b-Q8_0.gguf -c 8192 -np 1 -ngl 99 --port 8080

Settings and the API key (if any) are stored on this computer only.
